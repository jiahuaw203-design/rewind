# 阶段三 · 分支结构与结局设计 v3

> 承接 `阶段三_故事大纲_v2.md`（故事节点不变，本文件只解决"选项如何真的改变结局"）
> 目标：**4 个真分支点 + 5 个结局**，让玩家第一次通关后想"如果我当时不那样"。

---

## 一、三条设计纪律（先立规矩，否则分支会变成装饰）

1. **结局分支的选项，永远不许被 swap（错位执行）。**
   机制 B 的"点左边执行右边"只能用在**行动型选项**（关电视、问狗、去厨房）上。
   一旦玩家发现"连决定结局的那个按钮都在骗我"，他会认为整场游戏的选择都是假的，机制失效。
2. **每个结局之前，必须有一次看得见的分岔。**
   至少 2 个选项、文字清楚、不用小字、不用血字（血字留给"已经来不及了"的时刻）。
3. **同一结局，允许文本变体，但不允许换场景。**
   变体靠 flag 拼一句话（比如"我早就见过这一幕"），控制成本。

## 二、四个真分支点

### BP1｜幕一末：走，还是留（第一次证明"你的选择算数"）
- 位置：阿磊说"走吧，吃饭"之前，我察觉到带子不对劲。
- 选项：
  - `我要走了` → 阿磊挽留："就吃个饭。"
    - 二级选项：`还是算了` → **进入 E0**
    - 二级选项：`行吧` → 回主线
  - `这带子哪来的` → 主线（他答"哪个带子？"）
  - `好` → 主线
- flag：`left_early`
- **设计意图**：让玩家在 3 分钟内就摸到"原来真能走"。敢给，后面的恐怖才有重量。

### BP2｜幕三：狗没了，你先信谁
- 位置：回到家发现狗不在。
- 选项：
  - `问阿磊，狗呢` → 执行"我张了张嘴，没有出声"（swap）→ `mute +1`
  - `自己找一圈` → 找到狗窝是热的 → `found_warm +1`
  - `直接放带子` → 跳过质问 → 无 flag
- flag：`suspect`（= mute + found_warm）
- **影响**：不改结局归属，只改 E1、E2 的**结尾一句话**。
  - `suspect ≥ 1` 时，阿磊举刀那一幕多一句：`他早就在等我回头。`
  - 这是"低成本高回报"的变体，不增加场景。

### BP3｜幕五：带子，要不要带走（第三条真分支，也是唯一的"出口"）
- 位置：洗完澡，客厅空了，录像机还在转。
- 前置：在幕四选过 `把带子拿出来`（会发现带子卡住了）→ 这里才出现 `用力拔出来`。
- 选项：
  - `用力拔出来，装进包里` → `has_tape = true` → **进入 E3「带走」**
  - `再看一遍` → 回主线第四轮
  - `喊他` / `去厨房看看` → 回主线
- **设计意图**：这是全篇唯一一个"我带着东西离开了这间屋子"的路径。它必须存在，否则玩家会觉得无论怎么选都是死。

### BP4｜终局：站着不动，还是跑（两个主干结局）
- 位置：回头，看见阿磊举刀。
- 选项：
  - `站着不动` → **E1「看完」**
  - `往门口跑` → **E2「剪辑」**
- 说明：血字选项 `别回头` 出现在这两个选项**之前**，它不分支，它只负责把情绪压到底——点下它，才出现上面这两个真选项。

### BP5｜第二周目专属：提前关电视（机制 C 的回报）
- 触发条件：`meta_save.playthrough ≥ 1`
- 位置：第四轮播放**开始前**（不是终局）
- 新增选项：`先把电视关掉`（第一周目没有这个选项）
- 结果：**E4「玻璃」**
- **设计意图**：让"重开"这件事**有实际收益**，而不只是一个彩蛋。玩家会觉得"我上次学到的东西，这次能用了"——这是元游戏最爽的一刻。

## 三、分支图

```
幕一 门口
 ├─「我要走了」→「还是算了」────────────────────────→ E0 没吃成
 └─留下
    └─ 第一轮播放（空带）
        ├─ 快进 ──→ flag: saw_frame（看见那一帧背影）
        ├─ 倒回 ──→ flag: heard_steps（听见拖鞋声）
        └─ 关掉 ──→ 无
        幕三 狗没了
        ├─ 问阿磊（swap，哑口）──┐
        ├─ 自己找（狗窝是热的）──┼→ suspect +1（只改结尾一句话）
        └─ 直接放带子 ───────────┘
        幕四 猫没了
        └─ 「把带子拿出来」→（幕五解锁）「用力拔出来，装进包里」
                                        └────────────→ E3 带走
        幕五 洗完澡，客厅空了
        ├─ 喊他 / 去厨房看看 → 第四轮播放
        └─ 拔带子 → E3
        终局 回头，刀
        ├─「别回头」（血字，不分支，只压情绪）
        ├─ 站着不动 ─────────────────────────────────→ E1 看完
        └─ 往门口跑 ─────────────────────────────────→ E2 剪辑
        第二周目（playthrough ≥ 1）
        └─ 第四轮播放前新增「先把电视关掉」───────────→ E4 玻璃
```

## 四、五个结局

### E0｜没吃成（最短，2–3 分钟）
**触发**：幕一坚持离开。
- **场景**：楼道。我站在门外，听见里面的电视声，一直响到十二点。
- **三行收尾**：
  - "下楼的时候，声控灯一直没亮。"（梦核：连灯都不认我）
  - 第二天早上，门口地上有一盘带子，没有标签。
  - 字幕 `[血]`：`下一顿，我等你。`
- **冷点**：我走了，可带子还是到了我门口。**走不掉**——只是从"今晚"推迟到"明天"。
- **作用**：告诉玩家，"退出"也是被允许的，而且退出有代价。

### E1｜看完（主线，站着不动）
**触发**：终局选 `站着不动`（且 `has_tape = false`）。
- **场景**：刀落下前一刻白屏 `[闪]` → 客厅，暖黄灯，风扇在转。
- **关键**：**我坐在沙发上**，手里拿着遥控器，电视里**有画面**了。
  - 画面里：有人推开门进来，换鞋，坐下。
- **收尾**：
  - 字幕 `[血]`：`这盘带子没有标签。`
  - 左下角几乎看不清的小字：`第 4 次播放结束。`
- **变体**：
  - `saw_frame` → 加一句 `我早就见过这一幕。`
  - `suspect ≥ 1` → 加一句 `阿磊没有把刀放下。他不需要了。`
- **冷点**：我从"被拍的人"变成了"放带子的人"。下一次，我等的就是下一个我。

### E2｜剪辑（主线，往门口跑）
**触发**：终局选 `往门口跑`。
- **场景**：门开了。门外是**同一个客厅**——同样的塑料桌布、同样的风扇、同样停在七月的挂历。
- 沙发上有个背影，正在放一盘带子。我喊他。他回头。**他是我。**
- **收尾**：
  - 字幕 `[血]`：`门在这里，从来不是用来出去的。`
- **变体**：
  - `has_tape = true` → 我手里还攥着带子，而沙发上那个人手里**也有一盘**。
  - `heard_steps` → 多加一句 `刚才那个脚步声，是我自己的。`
- **冷点**：我不是跑出去了，我是从"被拍"跳到了"正在拍"——**门就是剪辑点**。

### E3｜带走（第三条分支）
**触发**：幕五选 `用力拔出来，装进包里`。
- **场景**：楼道很静，我一口气跑下楼。回家，半夜，我把带子放进**自己家的**录像机。
- **画面**：阿磊家的客厅。阿磊在厨房剁肉。他停下刀，抬头，正对镜头。
  - 字幕 `[血]`：`你怎么才回来。`
- **收尾**：屏幕右下角时间码 `00:00:00` 开始自己往前跳 `[码]`，一直跳，跳到我关掉电视为止。
- **冷点**：它没留在那间屋子。因为它要的从来不是那间屋子，是**一个愿意再放一次的人**。我把带子带回了家，也把那一晚带回了家。

### E4｜玻璃（第二周目专属）
**触发**：`playthrough ≥ 1`，第四轮播放前选 `先把电视关掉`。
- **场景**：电视黑了。黑玻璃映出客厅。
  - 但客厅里没有我。只有阿磊、狗、猫，三个都在，围着茶几，在看一盘带子。
  - 而我站在**屏幕外面**。
- **收尾**：
  - 我抬手。玻璃里的"我"没有抬手。
  - 字幕 `[血]`：`原来我一直在玻璃里面。`
  - 标题变化：`倒带` → `请勿倒带` → `已倒带 2 次` `[抖]`
- **冷点**：第一周目里我被拍了进去，所以第二周目我以"画面里的人"身份回到这间客厅。**能提前关电视，是因为我已经不在外面了。**

## 五、结局路由表（引擎判定顺序，阶段五直接用）

| 优先级 | 条件 | 结局 |
|---|---|---|
| 1 | `left_early == true` | E0 没吃成 |
| 2 | `has_tape == true` | E3 带走 |
| 3 | `final_choice == "stay"` | E1 看完 |
| 4 | `final_choice == "run"` | E2 剪辑 |
| 5 | `playthrough >= 1 && clicked_power_off == true` | E4 玻璃 |

> 说明：E4 必须在**播放前**判定，优先级高于 E1/E2——因为选了"关电视"就根本不会走到终局。

## 六、对 v2 节点大纲的 6 处修改

| 位置 | 原样 | 改为 |
|---|---|---|
| N03（阿磊说去吃饭） | 三个平行选项 | 加二级追问「还是算了」，通向 E0 |
| 幕三 N15 | `问阿磊` 执行哑口 | 保持（swap 只在这里用），但增加 `suspect` 计数 |
| 幕四 N25 | `把带子拿出来` 只是拿不出 | 改为**分两步**：这里发现卡住 → 幕五才解锁"用力拔" |
| 幕五 N36 | 三个选项 | 增加 `用力拔出来，装进包里`（E3 入口） |
| 终局 | 三个选项直接分结局 | 改为：血字 `别回头`（不分岔）→ 再出 `站着不动` / `往门口跑` |
| 第四轮播放前 | 无 | 第二周目新增 `先把电视关掉`（E4 入口） |

## 七、结局收集页（很小的投入，很大的留存）

标题界面下方一行：
`已播放：1 / 5`  →  未解锁的显示为 `未播放`（灰色 `[吃]` 效果）

- 五个结局各占一个位置，名字不给（避免剧透），只给编号与一句味道很淡的提示：
  - E0 `门口`
  - E1 `客厅`
  - E2 `门`
  - E3 `包`
  - E4 `玻璃`
- 作用：让"重开"变成有目的的行为，也正好把机制 C 的双存档用上。

## 九、待确认（2 个）

1. **5 个结局够不够？** 若要更多，建议不要再加，而是把 E1/E2 的变体文本写厚（成本低、收益高）。
2. **E0「没吃成」** 这个"提前退出"的结局，你想要吗？
   - 要：三条路都可走，玩家第一次就敢尝试；
   - 不要：第一幕不给退路，恐怖压强更大，但玩家会觉得被锁死。
