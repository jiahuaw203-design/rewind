# 剧本设计 · 四章与五结局（v0.9）

> 这一版剧本是按用户给的四章规格整篇替换旧六幕的。旧稿归档在 `docs/archive/`。
> 状态：**第一章已落地（24 节点）**；第二至四章、五个结局节点尚未入库，等第一章实测确认后再写。

## 一、一句话故事

我 1997 年夏天去阿磊家，他家里有一条黄狗、一只白猫，还有一盘没有标签的录像带。带子里录的不是节目，是这间屋子——录到了狗，狗就没了；录到了猫，猫也没了；录到最后，带子里出现了阿磊，和站在镜头后面的我。

## 二、全局设定

- **界面语言**：中文。
- **恐怖点**：失去控制感。不靠贴脸，靠"我明明看着，却什么都没做成"。
- **推进方式**：纯点击选项。选项文字可有血字 / 抖动 / 吃掉三种效果。
- **体量**：四章，单周目 20–30 分钟；五个结局靠二周目收集。

## 三、章节结构

### 第一章 · 到访（已落地）

| 段落 | 节点 | 作用 |
|---|---|---|
| 楼道 | `CH1_ARRIVE` / `CH1_ARRIVE_B` | 声控灯、门后雪花声。给玩家第一次"要不要多听一会儿"的选择 |
| 客厅 | `CH1_LIVING` → `CH1_PET_CAT` / `CH1_PET_DOG` / `CH1_NO_PET` | 摸猫（记住斑纹）、摸狗（E5 前置）、都不摸 |
| 旧货市场 | `CH1_MARKET` hub + 四个摊 + `CH1_MARKET_OUT` | 限翻 3 摊；空带是主线，旧照片 / 花封面带 / 铁盒是干扰；翻满三摊没拿到，阿磊兜底 |
| 饭馆 | `CH1_DINNER` → `CH1_TOPIC` + 五个话题 → `CH1_TOPIC_END` | 阿磊垫纸巾（第四章回收）；四选二话题；问疤需先问女朋友 |
| 回去 | `CH1_END` / `CH1_END_B` → `CH2_START` | 喊狗没回应；狗窝边一小堆新土；顺手试门（E4 的钥匙） |

第一章的 flag 产出：`petted_cat`、`petted_dog`、`has_blank_tape`、`tissue_detail`、`stall_unlocked`、`checked_door`、`saw_fresh_soil`、第二周目 `topic_dog`；线索一条 `scar_asked`。

### 第二章 · 五个地方（待入库）

- 阿磊出门买酒，吊扇嗡。**五个探索点，一共三次机会**（`explore_left: 3`），另一个录音带播放额外再扣 2。
- A 床头柜：花封面带、空带上「给你」二字；播放 → 狗刨土录像（`dog_tape`、`dog_familiar`、`watched_dog_tape`）。
- B 狗窝：凉的窝、一撮黑毛、阳台门没闩（`dog_absent`、`black_hair`、`balcony_unlatched`、`checked_dog_bed`）。
- C 猫碗与窗台：潮了的干粮、比猫爪大的爪印、窗台泥脚印、窗缝（`cat_bowl_empty`、`big_paw_print`、`window_mud`、`window_ajar`）。
- D 刀架与砧板：空槽、干砧板上的湿印、搪瓷盆暗红水、铁锈味（`knife_missing`、`cutting_board_dry`、`red_water`、`rust_smell`、`checked_kitchen`）。闻那盆水 = 额外耗一次并 `tension +2`。
- E 床：一边睡痕、便利贴「骨头汤，明天」、单人被（`bed_one_side`、`sticky_note`、`single_quilt`、`checked_bed`、`looked_back_at_bed`）。
- 次数用完强制 `CH2_ALLY_BACK`，阿磊的脚步声回来。
- 次数用文字暗示，不显示数字：喊价 → 收摊铁架 → 巷口有人说话 → 单元门响一下 → 脚步声。

### 第三章 · 录像机自己响了（待入库）

- 洗完澡出来，客厅没人，电视黑着。清点异常：啤酒没喝、狗窝空、猫碗空。
- 三卡带分支：按播放 / 按倒带（时间码 00:07:20 → 00:07:19，只退一秒，`timecode_anomaly`）/ 关电视（关了又自己亮，`tv_off_early`，`tension +2`）。
- 正片：猫啃肠子、剁肉声「咚。咚。咚。」单独成行；「屏幕里的声音和客厅里的声音，是同一个」单独成行。
- 带子卡住、手指划伤，三选：用力拔（`hand_injured` + `white_face`）/ 看时间码（`timecode_anomaly`）/ 拔电源（`tv_off_early`）。
- 阿磊回来时有三版条件文本：提前出来（`tv_off_early`）/ 推上柜门（`smelled_bowl`）/ 正常版。

### 第四章 · 他站在我面前（待入库）

- 开场三选：坐下（回收纸巾）/ 站着不动（`tension +1`）/ 先开口（灰显台词表）。
- 台词表五条，未获得的灰掉不可点：女朋友、疤（需 `stall_unlocked`）、时间码（`timecode_anomaly`，解锁 `CH4_WINDOW`）、刀架（`checked_kitchen`，`tension +1`）、床（`checked_bed`，`tension +2`）。
- 核心抉择：回头 / 喊他名字 / 冲向门口。`tension >= 6` 时**限时 5 秒**，超时走缓冲：`clues >= 3` 给第二次机会，否则 E1。
- 分支节点 `CH4_LOOK_BACK`、`CH4_CALL`（E5 隐藏线）、`CH4_STALL`（需 `stall_unlocked`）、`CH4_WINDOW`（需 `timecode_anomaly`）、`CH4_SEE`、`CH4_RUN`。

## 四、结局优先级（从高到低，先命中先返回）

| 顺序 | 结局 | 条件 |
|---|---|---|
| 1 | **E5** 布条 | `watched_dog_tape` + `checked_dog_bed` + `petted_dog`，且走 `CH4_CALL`（喊他名字） |
| 2 | **E3** 电话 | `timecode_anomaly` + `clues >= 3` + `stall_unlocked`，且在 `CH4_SEE` |
| 3 | **E4** 门 | `checked_door`，且在 `CH4_RUN` |
| 4 | **E2** 砧板 | `CH4_SEE` 但不满足 E3 / `CH4_RUN` 但没有 `checked_door` |
| 5 | **E1** 回头 | 超时且 `clues < 3` / 选「回头看他」/ 没有时间码却选「回头」 |

五句收尾（已写进 `data/endings.json` 与后续结局节点）：

- E1：**你已经回头了。**「狗还在院子里刨土。」
- E2：**你找到了。但你没跑掉。**
- E3：「狗刨土，刨的是它想让你看见的东西。」
- E4：**你什么都没看到。你只是跑了。**
- E5：「狗刨土，是因为它知道土里有什么。」

## 五、UI 纪律（三条不能说破的事）

1. **笔记本**只按获得顺序列中文描述。不显示总数、不显示百分比、不显示"还剩几条没找到"——一显示，玩家就开始做任务，而不是做噩梦。
2. **紧张度**不显示数字。>= 6 时选项轻微抖动，部分节点限时 5 秒。抖动幅度 0.8px，刚好让玩家怀疑自己眼花。
3. **探索次数**不显示数字，只用环境声文字。玩家数不清还剩几次，才会真的怕走下一步。
