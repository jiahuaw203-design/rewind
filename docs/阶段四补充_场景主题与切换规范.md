# 阶段四补充 · 场景主题系统与切换规范

> 依据：你给的三张参考图 → **粗网点纸 + 格纹桌布 + 绿字终端 + 老彩电/卡带 + 过曝暖黄**
> 结论：不做图片、不做动画的前提下，"梦核"靠**配色 + 纹理 + 光**三样撑起来，且整屏可换。
> 实现：`css/scenes.css`（纯 CSS，零图片资源）+ `preview.html`（可点的场景预览页）

## 一、从参考图里抽出的五条视觉语言

| 语言 | 出处 | 在本作怎么用 |
|---|---|---|
| **粗网点纸** | 卡带那张的波点背景 | 全屏叠加 3–6px 圆点，`mix-blend-mode: multiply`，是所有场景的"底噪" |
| **格纹桌布** | 90 年代花桌布、圆点布 | 客厅场景叠一层极淡的双向条纹（7px 一格），暗示"这是别人家" |
| **绿字终端** | Google 84 那张的荧光绿 + 进度条 | 只在"带子画面"场景出现：绿字、绿外发光、双倍扫描线 |
| **过曝暖黄** | 老彩电那张灯泡式的暖光 | 客厅、结局场景的核心光，靠 `radial-gradient` 光晕做，不是滤镜 |
| **白噪 + 扫描线** | 三张都有 | 全屏扫描线常驻；场景切换时用雪花擦除 |

> 关键判断：参考图里最"梦核"的不是内容，是**过饱和的旧**——暖得过头、亮得过头、网点粗得像印刷品。所以每个场景的 `--accent` 都必须比正常值更亮一点。

## 二、七个场景（与 `data/script.json` 的 `scene` 字段一致）

| 编号 | 场景 | 底色 | 主色 | 纹理 | 一句话感觉 |
|---|---|---|---|---|---|
| s0 | 楼道 | `#07090b` | 冷青 `#8fd9c9` | 顶部一束灯光渐变 | 湿、冷、声控灯不亮 |
| s1 | 客厅 | `#171208` | 暖黄 `#ffd27a` | 格纹 + 顶部光晕 | 太暖了，暖得像假的 |
| s2 | 带子画面 | `#020906` | 荧光绿 `#5cf59b` | 双倍扫描线 + 绿光晕 | CRT 里套着一台 CRT |
| s3 | 厨房 | `#0c0605` | 干掉的红 `#8b0f12` | 硬斜向阴影 + 角落红光 | 刀、砧板、背光 |
| s4 | 空客厅 | `#131312` | 灰 `#8b8a80` | **无纹理、关闭扫描线** | 颜色被抽走，电视是黑的 |
| s5 | 结局客厅 | `#221808` | 更黄的暖 `#ffe08a` | 密集网点 + 黄光晕 | 更旧、更黄、更像记忆 |
| s6 | 白屏 | `#e9e4d7` | 反相深棕 | 无 | 过曝的白，E1 的转场 |

**s4 的"无纹理"是故意的**：全篇只有一个场景可以安静到没有扫描线，就是洗完澡出来、电视已经黑了的那一刻。其余场景都有扫描线。这个"少了一层"会被玩家察觉，但说不出为什么。

## 三、场景切换规则（这是"每次都要切换"的落地方式）

1. **切换由节点驱动**：每个节点带 `scene` 字段。引擎发现和上一节点不同，就切一次。同一场景连续多个节点**不重复切换**（否则 15 分钟会切几十次，变成幻灯片）。
2. **切换动效统一**：雪花擦除 0.55s，中间闪一下场景名（`客厅` / `厨房` …）。
   - 0ms 加 `is-wiping` → 雪花层从上扫到下
   - 260ms 换 `data-scene`（整屏配色 0.8s 过渡过去）
   - 560ms 移除 class
   - **关键**：擦除动画跑到一半才换调子，视觉上才像"剪切"，不像"渐变"。
3. **全篇切换次数上限 ≤ 20 次**（v1.0 剧本实测 18 次，已通过）。
   比原定的 12 次放宽，原因是：**"进带子画面 / 出带子画面"本身就是一个剪辑点**——每轮播放都是一次 s1 ↔ s2 的往返，四次播放天然多出 8 次。
   这 8 次不是运输，而是叙事：电视一开，颜色从暖黄掉进绿字；电视一关，又爬回来。
   真要让次数变少，只能合并短节点，代价是节奏变钝——**不划算，所以放宽，而不是删节点**。
   硬约束仍然保留：同一场景连续多个节点不重复切换；单次切换动画固定 0.55s，全篇累计不超过 11 秒。
4. **同一场景可以复访**：洗完澡回客厅（s4）、结局回客厅（s5），都是"同一个空间的另一个版本"。这是本作最有效的恐怖手段之一——**空间没变，调子变了**。

## 五、给阶段五的接口约定

```js
// 引擎里只需要这一段
function setScene(id, label) {
  if (document.documentElement.dataset.scene === id) return; // 同场景不重切
  wipeLabel.textContent = label;
  document.documentElement.classList.add('is-wiping');
  setTimeout(() => { document.documentElement.dataset.scene = id; }, 260);
  setTimeout(() => { document.documentElement.classList.remove('is-wiping'); }, 560);
}
```

剧本里写场景，代码里不写：

```json
{ "id": "a2_05", "scene": "s2", "text": ["00:07:20 —— 画面里，阿磊在剁肉。"] }
```

## 六、可调参数（想改哪儿改哪儿，都在 `css/scenes.css` 顶部）

- `--halftone-size`：网点大小。**4px 最像印刷品，6px 最像扫描件**，别超过 8px，会脏。
- `--halftone`：网点浓度。客厅用带暖调的深棕（`rgba(56,36,8,.4)`），比纯黑更"旧"。
- `--vignette`：暗角强度。0.7 尚可呼吸，0.95 就是"只剩一盏灯"。
- `--tex`：场景纹理，可写多层渐变。想加格纹就加 `repeating-linear-gradient`。
- 切换速度：改 `wipe-run` 的 0.55s 与 JS 里的 260ms/560ms，三个数要一起改。

## 七、这一版没有做的（说清楚，别当成漏了）

- **不做图片、不做视频、不做背景动画**（沿用你最初的要求，也符合需求文档"明确不做"）。
- 所以"梦核"目前只到**配色/纹理/光**这一层。若以后想加"半透明旧照片贴片"，那会引入图片资源，需要你另行同意。
- 时钟、风扇、啤酒罐这些**具体物件仍是文字描述**，没有做成图形元素。
