> 完成时间：2026-11-17

## 一、剧本换了，引擎怎么换

旧六幕（70 节点）已整篇归档：`docs/archive/script_v1_六幕.json`、`docs/archive/剧本_全篇_v1_六幕.md`、`docs/archive/剧本_分幕_工作稿_v1_六幕.md`。只读，不再改。

用户给的是 Harlowe 语法规格，但已拍板**不换 Twine**，所以把 Harlowe 的写法逐条翻成数据字段：

| Harlowe 写法 | 本引擎里变成 |
|---|---|
| `(set: $x to true)` / StoryInit | 节点 `set: ["x"]`；开档初值写 `script.init` |
| `(set: $clues to it + (a: "id"))` | 节点 `clue: ["id"]`，引擎去重后按获得顺序进笔记本 |
| `$tension += 2` | 节点 `tension: 2` |
| `$explore_left -= 1` | 节点 `spend: {"explore_left": -1}`（任意计数器通用） |
| `(if: $x)[…]` 条件文本 | `text` 里写 `{"if": ["x"], "say": "…"}` |
| `(if: …)[(goto: "Y")]` 进门即跳 | 节点 `route: [{"when": ["…"], "next": "Y"}]` |
| 选项 `(if:)` 可用 / 灰显 | 选项 `requires: [...]` + `grey: true` |
| `(live: 5s)[(goto: "TIMEOUT")]` | 节点 `time_limit: 5` + `timeout: "CH4_TIMEOUT"` |
| `[[重新开始->StoryInit]]` | 选项 `next: "#title"`（特殊跳转） |

## 二、引擎的判定顺序（这条比代码本身重要）

进入一个节点：

1. **route 先跑** —— 按顺序看 `[{when, next}]`，先命中先跳走，本节点正文不渲染。（市场翻满三个摊 → 直接出市场；话题问满两个 → 直接收盘。）
2. 写 `set` / `clue` / `tension` / `spend`。
3. 切场景（仅当与上一节点不同）→ 打正文（含条件文本）→ 挂特效。
4. 出选项。

出选项时：

1. `lock` 未满足 → **不渲染**（跨周目功能，玩家不该知道它存在）。
2. `requires` 未满足 → **不渲染**；带 `grey: true` 的则渲染成灰色不可点。
3. 命中 deviation（仅 `kind:"action"`）→ 改跳 target（只此一次）。
4. 正常跳转。

节点带 `ending` 时：打收尾血字 → 解锁结局 → `playthrough + 1` → 清空 `game_save` → 结局卡。

写反任何一条，选择都会变成"假的"；玩家一旦察觉，恐怖就失效了。**这条是设计纪律，不是代码细节。**

## 三、新扩展的四件事

| 能力 | 落在哪 | 约束 |
|---|---|---|
| 线索笔记本 | `data/clues.json` + `#noteBtn` / `#notePanel` | 只按获得顺序列中文描述；不显总数、不显百分比、不显未解锁项；新线索图标闪两秒 |
| 紧张度 | `counters.tension` | 不显示数字；`>=6` 时 `.choices` 加 `.tense`（0.8px 抖动）+ 部分节点限时 5 秒 |
| 探索次数 | `counters.explore_left` / `flips` | 不显示数字，用环境文本提示（见第一章市场、第二章五探索点） |
| 灰显台词 | 选项 `requires` + `grey` | 未获得的台词灰掉且点不动，等于把"你知道多少"摆在玩家眼前 |

限时条：`#timerBar` 从 100% 匀速收到 0%，纯视觉，不报秒数。超时**不直接死**，先走 `timeout` 缓冲节点。

## 四、第一章落地清单（24 节点）

`CH1_ARRIVE → CH1_ARRIVE_B`（门口再听一会儿）→ `CH1_LIVING`（摸猫 / 摸狗 / 都不摸）→ `CH1_GO_OUT` → `CH1_MARKET`（四摊 hub）→ `CH1_STALL_TAPE / PHOTO / FLOWER / JUNK` → `CH1_MARKET_OUT`（三个摊翻完，阿磊兜底给带子）→ `CH1_DINNER`（垫纸巾）→ `CH1_TOPIC`（四选二）→ `CH1_T_GF / HOUSE / SCHOOL / SCAR / DOG` → `CH1_TOPIC_END` → `CH1_END`（新土）→ `CH1_END_B` → `CH2_START`（待接入占位）

刻意比规格的"约 8 节点"拆得更细：**只有拆开，摊位的"次数"和话题的"后果"才落在数据上**，而不是写死在正文里。

三处关键实现：

- **限翻三个摊**：`flips: 3`，每个摊 `spend: {"flips": -1}` 并写 `flipped_xxx`；hub 的 `requires: ["!flipped_xxx"]` 让翻过的摊从选项里消失；`route` 里 `flips<=0` → `CH1_MARKET_OUT`（阿磊兜底，保证主线拿得到空带）。
- **四选二话题**：`topics` 计数，每个话题 `spend: {"topics": 1}`，hub 的 `route` 在 `topics>=2` 时直接跳 `CH1_TOPIC_END`（老板娘上完两道菜强制结束）。
- **问疤要先问女朋友**：疤选项 `requires: ["topic_gf"]` + `grey: true`，灰着摆在那儿；问到才 `stall_unlocked` + 线索 `scar_asked`。

## 五、实测记录（2026-11-17，localhost:8230）

| 测什么 | 结果 |
|---|---|
| 标题页 / 开新档 | 通过；`init` 写入 `tension 0 / flips 3 / topics 0`、`clues []` |
| 门口"再听一会儿" | 通过，回来还能敲门 |
| 摸猫 / 摸狗 / 都不摸 | 三条都通，分别写 `petted_cat` / `petted_dog` / 都不写 |
| 市场翻三个摊（照片→花封面→铁盒） | 环境提示逐级变化（喊价 → 收铁架 → 巷口说话）；摊翻过即消失；`flips` 归零后自动跳 `CH1_MARKET_OUT`，阿磊兜底给带子 |
| 市场直接翻到空带 | `flipped_tape` 命中 route，**跳过剩下摊位直接进饭馆**（不是回到 hub） |

## 六、跨周目的三层变化

| 层 | 存在哪 | 玩家能不能清 |
|---|---|---|
| 本轮进度（当前节点、flag、线索、计数） | `rewind.game_save` | 能（清掉 = 重来） |
| 通关次数、已解锁结局 | `rewind.meta_save` | **不能**，只增不改 |
| 解锁规则 / 标题阶段 | `data/meta.json`（只读） | 不是存档，是规则表 |

第二周目的两处残留由 `meta.json` 的 `unlocks` 驱动：`meta2_question`（playthrough ≥ 1）。引擎开档时把它们写进 `state.granted`，选项用 `lock` 引用。
