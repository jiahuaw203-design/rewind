# 阶段二 · 竞品盘点与候选玩法机制

> 承接《游戏核心需求文档 v1.0》｜核心恐怖点：失去控制感｜推进：纯点击｜体量：10–15 分钟｜外壳：90 年代录像带
> 本阶段目标：从市面成熟作品里提炼出 **3 种适配我们技术栈（HTML/CSS/JS + JSON、无服务器、localStorage）的机制**，供你挑选。
> 注意：只借鉴**结构性做法**，不复制任何素材、文本、美术。

---

## 一、竞品盘点（按"和我们像不像"排序）

### 1. 同构度最高：SCP-5571（基金会文档式条目）
一个"纪录片电子版"设定：**当它被播放时，异常才开始发生**。
- 可借鉴：**恐怖的载体就是"播放这个动作"本身**。玩家不是在读故事，而是在"放一盘不该放的带子"。
- 我们的差异：它靠文档描述，我们靠玩家亲手按播放键。

### 2. 机制教科书：Doki Doki Literature Club（DDLC）
恐怖不靠画面，靠**游戏对玩家越权**：让角色直视玩家、喊出系统用户名、移动鼠标指针、**删掉别的角色的存档文件**，最终要求玩家去游戏目录手动删文件才能继续。
- 可借鉴：**"存档"是可以被剧情动用的道具**，不是后台数据。
- 风险：它做的是"删你真实文件"，我们不能、也不该做这么越界的操作。我们只做"存档里有我没写过的东西"。

### 3. 病毒式写法：IMSCARED
把游戏本身包装成"你电脑上多出来的一个文件"，用假崩溃、假报错、窗口异常来制造"我的设备被入侵了"的错觉。
- 可借鉴：**界面故障本身就是叙事**（我们要的第 2 层失控感）。
- 风险：假崩溃会让部分玩家以为是 Bug 而退出，需要"事后能解释"的设计。

### 4. 伪播出质感：Analog Horror（模拟恐怖）
一整类以"老电视播出/录像带"为形式的恐怖创作：画质噪点、台标、时间码、插播公告、信号中断。
- 可借鉴：**时间码与播放状态是天然的叙事计时器**，也是天然的"失控显示器"——时间码倒退，比任何文字都吓人。

### 5. 分支叙事参照：隐形守护者
真人影像 + 高频选择 + 大量分支与死亡结局，靠"选错就死"制造残酷感。
- 可借鉴：**选项密度与后果明确性**（玩家知道自己的选择有代价）。
- 不借鉴：它靠真人素材和影像，我们没有素材预算；且"选错就死"属于惩罚型，与我们要的"认知型结局"相反。

### 6. 线索整合参照：《头七》（2025）
把论坛灵异帖之间的关系拼起来，靠"从散落信息里看出关联"推进。
- 可借鉴：**让玩家自己发现矛盾**，而不是被直接告知矛盾。

### 7. 身份甄别参照：《寻找伪人》
核心是"判断眼前这个人是不是本人"，靠反复核对细节制造不安。
- 可借鉴：**"同一个东西，细节变了"** —— 这正是我们要的"读完的句子自己改一个字"。

### 小结：三条可复用的行业经验
1. **恐怖要有"载体动作"**：盘带子、按播放、看时间码——动作本身就是恐惧来源；
2. **越界要克制**：DDLC 敢删文件，我们只敢"写一行你没写过的字"，但效果足够；
3. **矛盾要让玩家自己发现**：直接告诉他"这里有问题"= 解除恐惧。

## 二、三种候选机制

> 三种都满足：纯点击、单场景、10–15 分钟、无服务器、JSON 可配置。
> 工作量按"已有通用引擎之后"的增量估算。

### 机制 A｜时间码驱动（VCR 四键即选项）

**一句话**：玩家的"选项"不是 A/B/C，而是录像机的 **播放 / 暂停 / 倒带 / 快进** 四个键；剧情推进 = 带子转到了哪一刻。

- **玩家体验**：屏幕下方永远有时间码 `00:03:41`。想往前推进就按播放，想退回刚才那句就按倒带——直到某一次，**倒带按下去，时间码往前跳了**。
- **怎么实现**：节点 JSON 里每个节点挂一个 `timestamp`；四键映射为 `next / hold / prev / skip`；一个 `vcrState` 状态机管住"这四个键现在允不允许用"。
- **失控点**（天然契合第 2 层）：
  - 某个节点开始，**暂停键无效**——画面里的文字继续走；
  - 倒带倒回去，**回去的那句话和刚才不一样**（同一个 timestamp 挂两个版本的文本，靠 `meta_save` 决定给哪个）；
  - 时间码在 `00:11:59` 停滞，再按播放直接跳到 `00:00:00`。
- **工作量**：中（需要一个时间码 UI + 状态机，约 2–3 天等效）。
- **风险**：四键语义要教清楚，否则玩家会迷路；建议第一分钟用"正常播放"把四键教完。
- **适配评分**：★★★★☆（最贴合"录像带"外壳，失控感可视化最强）

### 机制 B｜不可信选项（选择与执行错位）

**一句话**：玩家看到的选项，和实际执行的结果**不是同一个**；而且同一段剧情第二次进入时，选项文字已经变了。

- **玩家体验**：三个选项里点"关掉电视"，画面却显示"你把带子又倒回了开头"。玩家会怀疑自己点错——回去再点，这次结果对了。第三次，它又错了。
- **怎么实现**：JSON 每个节点除正常 `choices` 外，多一个 `deviation` 字段：
  ```json
  "deviation": {
    "trigger": "act2_door",
    "mode": "swap",          // swap=执行另一个选项 / vanish=选项消失 / rewrite=文字被改
    "target": "choice_b",
    "once": true             // 只发生一次，避免变成"每次都这样"的梗
  }
  ```
  引擎按 `deviation.trigger` 命中时，**照常渲染玩家点的那个选项文案，但跳到 `target` 的结果节点**。
- **失控点**（覆盖第 1、2 层）：
  - `vanish`：某个选项在玩家犹豫的 3 秒后**自己消失**（无提示，选项列表悄悄重排）；
  - `rewrite`：选项文字在被悬停/二次进入时**换了一个字**（"打开门"→"它打开了门"）；
  - `swap`：点左边执行右边，且**只在关键节点触发一次**。
- **工作量**：低（引擎多一个分支判断，主要成本在剧本设计）。
- **风险**：容易让玩家以为"游戏坏了"。必须靠**后续文本承认这件事**（"你刚才选的是这个吗？"）把 Bug 感转成恐怖感。
- **适配评分**：★★★★★（最贴合"失去控制感"这个核心恐怖点，成本最低）

### 机制 C｜带子记得你（双存档跨周目）

**一句话**：玩家有一个看得见的存档，还有一个**他不知道存在的**记录；"新游戏"并不会真的重来。

- **玩家体验**：第一遍通关后点"重新开始"。带子从头播起，但播到第 40 秒，主角说了一句**只有上一轮才可能知道的话**。结局后回到标题，**标题的名字变了**。
- **怎么实现**：`localStorage` 双键：
  - `game_save`：正常剧情进度（玩家可清）；
  - `meta_save`：只增不改的痕迹（通关次数、选过的关键选项、停留过久的节点）；
  引擎在特定节点读 `meta_save`，决定文本变体 / 标题变体 / 是否插入"陌生字迹"。
- **失控点**（第 3 层，压轴）：
  - 标题画面文案随周目变化（`倒带` → `请勿倒带` → `已倒带 3 次`）；
  - 存档界面上多出一行**不是玩家输入的文字**（例如"这一段我替你看了"）；
  - E3 结局：主角换名，但说话方式完全一致——同一盘带子的下一次播放。
- **工作量**：低（两个 key + 几张变体文案表），但**叙事收益最高**，是"重开才看见"的隐藏层。
- **风险**：必须**只做一次**、且放在最后；用多了会显得像彩蛋。
- **适配评分**：★★★★☆（收尾神器，不适合当主机制单独撑 15 分钟）

## 三、我的推荐组合

**主机制选 B（不可信选项），收尾用 C（双存档），A 作为外壳与氛围层（不承担主要叙事）。**

理由：
1. B 直接命中"选择失效"这一核心设定，成本最低，且能覆盖第 1、2 层的大部分桥段；
2. C 只做一次、放最后一次，正好是第 3 层的压轴，且**不需要额外美术**；
3. A 的四键如果全量做，会挤占 10–15 分钟的叙事时间；建议**只保留时间码显示 + 一次"倒带倒退"**，作为外壳质感与一次关键失控点，不把它做成完整的解谜系统。

即：**B 是骨架，A 是皮肤，C 是最后一刀。**
