# 阶段三 · 故事大纲 v2（《请勿倒带》）

> 依据你给的故事重写。机制不变：**B 不可信选项（骨架）+ A 时间码（皮肤）+ C 双存档（最后一刀）**
> 呈现不变：**纯文字 + 文字特效**，不做图片、不做动画、不做配音
> 氛围基准：**90 年代中国家庭 + 梦核（空、静、过曝、物件比人多）**

---

## 一、一句话

我去朋友家等一顿饭，等的时候放了一盘没有标签的录像带；那盘带子每播一次，这间屋子里就少一样活的东西——狗、猫、他，最后轮到坐在沙发上的我。

## 二、这个故事比上一版好在哪（我为什么原样保留你的骨架）

| 上一版的问题 | 你的版本给出的解法 |
|---|---|
| 只有结构诡计，没有人 | 有一顿没吃成的饭、两趟下楼、一次洗澡——**日常动作构成了时间轴** |
| 恐怖没有实体 | 狗、猫、刀、骨头、肠子、啤酒——**都是能摸到的东西** |
| 反转靠解释 | 反转靠**数量**：家里的活物从 3 个减到 0 个，玩家自己会数 |
| 没有动机 | 我只是"被邀请来吃饭"，什么都不图——**恐怖不需要动机，只需要巧合** |

## 三、三条硬规则（故事能自洽全靠它们，全篇绝不解释）

1. **被录进去的东西，会从房间里消失。**
   带子不是记录现实，是**收纳现实**。狗进了带子 → 狗不在家；猫进了带子 → 猫不在家。
2. **先有带子，后有这一晚。**
   带子里拍的是"将要发生的事"。所以每一次播放，都是**提前看了一遍今晚**。
3. **带子只有一个空位。**
   它需要四个人：狗、猫、朋友、我。前三段已经装满，第四段的位置留给**镜头后面那个人**——也就是我。

> 红线：**永远不解释带子从哪来、谁录的、为什么能录到"现在"。** 玩家能自己拼出规则，就是最好的效果。

## 四、角色

| 角色 | 设定 | 作用 |
|---|---|---|
| **我**（第一人称，无名） | 二十多岁，来朋友家等吃饭 | 唯一不知道规则的人；**唯一会进带子的活人** |
| **阿磊**（朋友） | 这家的主人，独居，说话很慢 | 他早就知道。他的每句台词都是**背下来的**（见桥段 3） |
| **狗** | 土狗，黄，见人就摇尾巴 | 第一次消失，第一次进带子 |
| **猫** | 白猫，不上人腿 | 第二次消失；**它是自己走进去的**（碗还是满的） |

## 五、四轮播放（故事的主干就是"看-少-再看"）

| 轮次 | 带子里播的是什么 | 播完之后，家里少了什么 | 玩家的心理状态 |
|---|---|---|---|
| 第 1 轮 | **空的**。只有雪花，和一帧看不清的背影 | 什么都没少 | "这带子是坏的" |
| 第 2 轮 | **狗**。狗在客厅转圈，走进厨房，门关上 | **狗没了** | "巧合吧" |
| 第 3 轮 | **狗和猫**。镜头一直往厨房门推 | **猫没了** | "不对" |
| 第 4 轮 | **阿磊、狗、猫**。厨房，剁肉，骨头，肠子 | **阿磊没了** | "我要走" |
| （第 5 轮） | **镜头后面那个人** | **我** | 结局 |

**关键节奏**：带子永远比现实**早一轮**。玩家在第 3 轮才反应过来——那时已经晚了。

## 六、逐幕节点大纲

> 标注说明：`[血]`血字 `[抖]`字符抖动 `[吃]`字被吃掉 `[打字]`打字机 `[闪]`雪花转场 `[码]`时间码变化
> 每幕只给"文本要点 + 代表台词 + 选项 + 特效"，完整台词在阶段五填满。

### 幕一｜到访（0–2.5 分）`[闪]`

- **N01 门口**。门里有电视声，很轻，像隔了一层棉被。阿磊开门："进来吧，鞋不用换。"
- **N02 客厅（梦核物件清单，必须具体）**：塑料桌布、玻璃茶几上的一圈水渍、转页风扇、彩电后盖的散热孔在响、冰箱嗡嗡、墙上的挂历停在七月。
  - 猫在窗台，狗在脚边。电视开着，**没有画面，只有雪花**。
- **N03 阿磊**："你等会儿啊，我俩一会儿出去吃饭。"
  - 选项：`好` / `现在就去吧` / `你家猫叫什么`
  - `你家猫叫什么` → 他没有回答，只是把电视音量调大了一格。（第一次轻微错位，玩家会以为是没听见）
- **N04** 他进了厨房。客厅只剩我、一只猫、一条狗、一台雪花电视。
- **N05 带子出现**：茶几下面，一盘没有标签的带子，带盒侧面有手写字。
  - **手写字是「请勿倒带」，第一个字被磨掉了**，看上去就是「倒带」。`[吃]`
- **N06** 选项：`放进录像机` / `喊一声阿磊` / `不动它`
  - `喊一声阿磊` → 没人应。雪花声大了一格。
  - `不动它` → 风扇停了一秒，又转起来。（时间感第一次失效）

### 幕二｜第一轮：空的（2.5–5 分）`[闪][打字]`

- **N07** 按播放。右上角出现绿色时间码 `00:00:00`。`[码]`
- **N08** 全屏雪花。字幕逐字打出：`1997 夏` `[打字]`
- **N09** 什么都没有。雪花里有一种节奏。文本："雪花不是均匀的。它有呼吸。"
- **N10** 选项：`快进` / `倒回去` / `关掉`
  - `快进` → 时间码跳到 `00:07:00`，**闪过一帧**：沙发上有个背影，0.15 秒，看不清。`[闪]`
    - **这是全篇最重要的埋点**（桥段 1）
  - `倒回去` → 回到 `00:00:00`，一切重来。但这次雪花里有"拖鞋在地板上走"的声音。
  - `关掉` → 触发固定事件：阿磊从厨房出来
- **N11 阿磊**："走吧，吃饭。"
  - 选项：`你这带子哪来的` / `刚才什么都没录` / `好`
  - `你这带子哪来的` → 他看了一眼茶几，**茶几上是空的**，他说："**哪个带子？**"
  - `刚才什么都没录` → "那可能是坏了吧。" 他把带子从机器里拿出来，放回茶几下面。（带子自己回到了原位）
- **N12** 黑屏。`[吃]` 字幕："四十分钟后。"

### 幕三｜第二轮：狗（5–8 分）`[闪]`

- **N13** 回到家。灯亮着，菜在桌上，没人动过。**狗不在门口。**
- **N14** 我叫了两声狗的名字。没有爪子声。冰箱在响。
- **N15** 选项：`问阿磊，狗呢` / `找一圈` / `打开录像机`
  - `问阿磊，狗呢` → **执行的却是"我张了张嘴，没有出声"**（第一次明显 swap）
    - 阿磊："怎么了？" 我说："没事。" `[抖]`
  - `找一圈` → 阳台、卧室、卫生间都找过。**狗窝是热的。**（埋点：它刚还在）
- **N16** 播放。时间码 `00:00:00`。画面是**这个客厅，这个角度，这盏灯**。
- **N17** 一条黄狗在地板上转圈，转了三圈，停下，**对着镜头叫了一声**。字幕只有一个字：`汪` `[打字]`
- **N18** 狗走进厨房。厨房门关上。画面变成厨房的门。
- **N19** 选项：`跟过去` / `暂停` / `叫阿磊来看`
  - `暂停` → **画面继续走**，时间码继续跳。（桥段 2）
  - `叫阿磊来看` → 他站在门口看了三秒，说："这有什么好看的。" **他一点都不惊讶。**
- **N20 阿磊**："好奇怪啊。" —— 注意：他先说"有什么好看的"（平静），后说"好奇怪"（惊讶）。**顺序是反的。**（桥段 3）
- **N21** "我想喝点啤酒，你跟我去买。"
- **N22** 带子自己倒回去了，机械声很响。`[码]` 时间码回到 `00:00:00`。

### 幕四｜第三轮：狗和猫（8–11 分）`[闪]`

- **N23** 楼下小卖部，来回十分钟。`[吃]` 字幕只给这一句。
- **N24** 回到家。**猫不在窗台了。** 猫的碗是满的，碗被推到地上。
- **N25** 选项：`猫呢` / `把带子拿出来` / `坐下，喝啤酒`
  - `把带子拿出来` → 它在机器里，**拿不出来**。带子卡住了。（第一次"物理反抗"失效）
- **N26 阿磊**："咱俩继续看吧。" 他没有找猫。他把啤酒放在桌上，**一口没喝**。
- **N27** 播放。狗在客厅，猫跟在后面。镜头一直在往前推，推向厨房的门。推得很慢，像有人端着机器在走。
- **N28** 字幕："它们知道门后面有什么。" `[打字]`
- **N29** **录像里有脚步声**（文字描述）：镜头后面有东西在走，很慢，拖鞋，一步，一步。
- **N30** 选项：`回头看身后` / `盯着屏幕`
  - `回头看身后` → 身后是空的客厅，风扇在转。**回头看屏幕，时间码已经跳到 `00:09:40`**（跳过了 40 秒，我根本没看那段）。`[码]`
  - `盯着屏幕` → 脚步声停在镜头后面，不动了。**它一直在那儿站着。**
- **N31 阿磊没有反应。** 他说："困了。咱睡吧。"
- **N32** 选项：`你不觉得这带子有问题吗` / `好` / `我要走了`
  - `你不觉得这带子有问题吗` → 他笑了："**什么问题？**" 停一秒："**什么问题？**" —— 同一句话问了两遍，语速一模一样。（桥段 4：他在等这句，已经答过很多次）
  - `我要走了` → 门把手转不动，但门没锁。这个选项**留着**，后面会消失。

### 幕五｜洗澡（11–13 分）

- **N33** 洗澡。水声、热水器点火、隔着门客厅电视的"滋——"。
- **N34** 出来。客厅**很安静**。电视是黑的。茶几上三罐啤酒，一罐开了，**没喝**。
- **N35** 阿磊不在了。狗窝空着。猫的碗在地上。
- **N36** 选项：`喊他` / `去厨房看看` / `打开录像机`
  - `喊他` → 只有冰箱的嗡嗡声。然后录像机**自己咔了一声**。
  - `去厨房看看` → 厨房是干净的。砧板是干的。刀架上少了一把刀。
  - **"我要走了"这个选项，从这一步开始消失了。**（桥段 5：唯一能离开的选项被收回了）

### 幕六｜第四轮：阿磊、狗、猫（13–16 分）`[血][闪][码]`

- **N37** 播放。时间码**不是从 `00:00:00` 开始**，是 `00:07:20`。`[码]`
- **N38** 我按了"倒带"。**时间码变成 `00:07:21`** —— 往前走了 1 秒。`[抖]`
  - 从这一刻起，所有按钮的意义都反了。（桥段 6）
- **N39** 画面：厨房。阿磊在剁肉。狗在旁边吃骨头。猫在旁边吃肠子。
  - 字幕：`咚。` `咚。` `咚。` `[打字]` 第三个"咚"延迟了一拍才出来。
- **N40** 我的胃在响。画面里的声音和客厅的声音**是同一个**（因为我听见厨房方向真的有人在剁东西）。
- **N41** 选项：`关掉电视` / `后退` / `再靠近一点`
  - `关掉电视` → **执行的是"我往前走了一步"**（最凶的一次 swap）
  - `再靠近一点` → 屏幕上的阿磊**变大了**，因为我离电视更近了，也因为镜头在推。
- **N42** 画面里阿磊停下刀。他转过身，正对镜头。他的脸**看不清**——不是没有五官，是像曝光过度。`[闪]`
  - 字幕：`他看见我了。` `[血]`
- **N43** 我一回头。
- **N44** 阿磊站在身后，举着刀。刀上什么都没有。他的脸也是这样，看不清。
  - 文本安静两秒（只有一个光标在闪）。然后出现最后的选项。

### 终局分支（16–18 分，血字选项）

三个选项里，**只有第一个能点**：

| 选项 | 状态 | 结果 |
|---|---|---|
| `别回头` | **血色，可点** `[血][抖]` | 但我已经回头了 → E1 或 E2 的分岔在此之后 |
| `跑` | 灰色，不可点 `[吃]` | —— |
| `（空白）` | 字被吃掉了，只剩痕迹 `[吃]` | —— |

点下 `别回头` 之后，才出现真正的二选一（正常白字，但字体比之前小一号——像被人改小了）：

- `站着不动`
- `往门口跑`

## 七、七个恐怖桥段（细思极恐，全篇零惊跳）

### 桥段 1｜空带里那一帧背影
- **表面**：快进的时候闪了一帧，太快了，看不清，玩家会以为自己眼花。
- **回头**：那盘带子**从来不是空的**。那一帧就是**我自己**——第四轮要拍的那个人。它在第一轮就给了我预告，只是太快。

### 桥段 2｜按了暂停，画面还在走
- **表面**：按钮没反应。
- **回头**：暂停这个功能从来不属于我。带子只有播放。而我以为我在控制它，其实**我从第一分钟就在被播**。

### 桥段 3｜他的台词顺序是反的
- **表面**：他先说"这有什么好看的"，后说"好奇怪啊"。
- **回头**：人不会先平静后惊讶。**他的反应是背下来的**——他早知道狗会消失，只是把台词说串了顺序。

### 桥段 4｜「什么问题？」问了两遍
- **表面**：他重复了一遍问句，像没听清。
- **回头**：他在**等这句问话**。已经有人问过他很多次，他每次都这么答。语速一样，是因为**这段被播过很多次**。

### 桥段 5｜"我要走了"这个选项自己消失了
- **表面**：选项列表短了一行，玩家以为记错。
- **回头**：那是全篇**唯一一个能离开的选项**。它不是被删的，是**被收回的**——因为它本来就是带子给的。第一次出现是在晚饭前，那时它还需要我留下。

### 桥段 6｜倒带键让时间码前进了 1 秒
- **表面**：按错了吧。
- **回头**：所有按钮的意义都反了。**倒带 = 快进**。也就是说，我一直想"回到刚才"，而它一直在把我**推向后来的事**。
  - 更冷的一层：我按了那么多次倒带，所以它才播得那么快。

### 桥段 7｜啤酒一口没喝
- **表面**：他只是忘了喝。
- **回头**：他不需要喝啤酒。他需要的是**让我离开房间十分钟**——这样他才有时间"被拍进去"。买啤酒这个提议，是带子的安排，不是他的。
  - 对应：结尾三罐啤酒，一罐开了，没喝。

## 八、三个结局

### E1｜看完（站着不动）
刀落下前一刻，**白屏**。`[闪]`
然后：客厅，暖黄的灯，风扇在转。**我坐在沙发上**，手里拿着遥控器。电视开着，有画面。
画面里：有人推开门进来，换鞋，坐下。
字幕：`这盘带子没有标签。` `[血]`
→ 只有一行小字，在左下角，几乎看不清：`第 4 次播放结束。`
**冷点**：我从被拍的人，变成了放带子的人。下一次，我等着的那个人，就是下一个我。

### E2｜剪辑（往门口跑）
门开了。
门外是**同一个客厅**——同样的塑料桌布，同样的风扇，同样停在七月的挂历。沙发上有个背影，正在放一盘带子。
我喊他。他回头。**他是我。**
字幕：`门在这里，从来不是用来出去的。` `[血]`
**冷点**：我以为跑出去了，其实我跑进了**剪辑点**——从"被拍"跳到"正在拍"的那一帧。

### E3｜换人（跨周目隐藏层，机制 C 专属）
第二周目：
- 朋友换了名字（阿磊 → **小陈**），猫狗一模一样，客厅一模一样。
- 第四轮播放时，带子里除了阿磊、狗、猫，**还有一个背影**——穿的是我上一周目的衣服。
- 存档里多一行不是我写的字：`这一盘，我替你放完了。` `[血]`
- 标题变化：`倒带` → `请勿倒带` → `已倒带 2 次` `[抖]`

## 九、文字特效清单（全部可用 CSS 实现，阶段五落地）

| 代号 | 名称 | 实现要点 | 用在 |
|---|---|---|---|
| `[血]` | 血色字 | 颜色 `#8b0f12`；出现时由灰**渐变到红**（0.8s）；字距 +0.5px 轻微错位 | 关键台词、最终选项、结局字幕 |
| `[抖]` | 抖动 | 单字符横向随机偏移 1–2px，每 80ms 变一次；幅度极小，像信号不稳 | "他看见我了"、"已倒带 N 次" |
| `[吃]` | 吃掉的字 | 某几个字逐渐变成背景色（0.6s 渐隐），只留一道浅浅的痕 | 被磨掉的"请"、空白选项、消失的选项 |
| `[打字]` | 打字机 | 逐字出现，但**偶发重复一个字**（`咚咚咚咚`），间隔不均匀 | 录像字幕、`1997 夏` |
