# 游戏核心需求文档 v1.0

> 项目代号（暂定）：**《倒带》** / Rewind
> 类型：文字微恐网页游戏（单场景 · 纯点击 · 分支叙事）
> 阶段：阶段一产出 · 待确认后进入阶段二（竞品调研与机制梳理）
> 日期：2026-11-16

---

## 一、一句话定位

玩家在一间深夜的旧客厅里看一盘**无标签录像带**，随着带子播放，他发现**这盘带子在控制他，而不是他在控制带子**——他点的每一个选项，都可能是带子替他选的。

## 二、三条已确认的核心设定

| 维度 | 决策 | 含义 |
|---|---|---|
| 核心恐怖点 | **失去控制感** | 恐怖不来自怪物，而来自"我的选择不算数了"：选项失效、存档被改写、界面反过来操纵玩家 |
| 推进方式 | **纯点击选项** | 不输入指令、不做可见数值条；玩家只做"选哪个"这一件事，判断全部来自文本阅读 |
| 体量 | **10–15 分钟小品** | 1 个场景、1 条主干、2–3 个结局，目标是把引擎与叙事规范一次跑通 |
| 题材外壳 | **90 年代录像带** | 家用录像机（VCR）、无标签磁带、时间码、模拟信号雪花、CRT 屏幕质感 |

## 三、体验设计：失控感必须"分三层递进"

这是本作唯一的设计主线。三层必须按顺序发生，且**强度递增、不可逆**——玩家一旦意识到"我被骗了"，就不能再回到第一层。

### 第 1 层｜选项不对劲（前 3 分钟）
- 选项文字出现**极细微的错字或语序颠倒**，玩家以为是自己的错觉；
- 某些选项在其他选项被选中后**悄悄消失**，没有任何提示；
- 同一个选项被点两次，第二次的执行结果和第一次不同。

> 设计红线：第 1 层**绝不解释**、**绝不弹提示**。玩家感到"好像哪里怪"，但说不出来。

### 第 2 层｜界面不对劲（第 4–9 分钟）
- 选项的**点击热区与实际结果错位**：玩家点左边，执行右边；
- 录像带时间码**倒退**，进度条不按玩家操作走；
- CRT 画面出现"暂停键失灵"——文字继续往下走，但界面显示已暂停；
- 文本在玩家读完后**自己改一个字**（"我关掉了电视" → "它关掉了电视"）。

### 第 3 层｜记忆与存档不对劲（第 10–15 分钟）
- 玩家**重开游戏**时，上一轮才有的记录仍在（localStorage 里的痕迹不随"新游戏"清空）；
- 标题画面在结局后**换了名字**；
- 存档里出现一条**不是玩家写的**文字。

> 设计红线：第 3 层只做**一次**、且放在最后。用多了会变成"梗"，而不是恐惧。

## 四、单场景的空间设定（决定所有文本的边界）

**场景唯一：90 年代某户人家的客厅，深夜。**
只有四件东西反复出现，所有叙事都在它们之间循环：

1. **电视 + 录像机**：唯一的"窗口"，玩家的视线来源；
2. **那盘无标签录像带**：故事本身；
3. **茶几上的遥控器**：玩家的"权力"象征（也是最先失灵的东西）；
4. **身后的沙发与门**：玩家"随时可以离开"的暗示（而这正是最大的谎言）。

**不做**：不切换场景、不做地图、不做物品栏漫游、不做角色立绘。全部通过"看带子"这一动作完成空间叙事。

## 五、叙事与恐怖桥段的设计原则

1. **细思极恐优先，禁止贴脸开大**：不用突然的音效爆点、不用突然弹出的脸。恐怖必须来自"读完之后的回想"。
2. **每个恐怖点都要能"回头看"**：玩家第一次读到时觉得正常，回想时才发现那句是预告。文本必须可被二次阅读。
3. **少即是多**：全篇正文控制在 800–1200 字区间（不含分支重复段），宁可留白。
4. **不解释超自然**：带子为什么能控制人——永远不给出答案。给答案等于解除恐惧。
5. **声音克制**：只有磁带转动的底噪、VCR 的机械声、偶尔的电流杂音。全篇最多 1 次"声音异常"。

## 六、结局需求（2–3 个，具体内容留到阶段三）

必须满足以下**结构性要求**（不是具体剧情）：

- **E1 服从结局**：玩家全程按"带子希望他选"的选项走，最终停留在"看完了"的状态——但最后一次操作不属于玩家自己。
  - 关键要求：结尾要出现**一句玩家在开头说过的话，被带子原样引用回来**。
- **E2 反抗结局**：玩家试图关掉电视/离开房间/拔掉电源，全部失败，最终意识到**"离开"这个选项本身就是带子提供的**。
- **E3（可选）重开结局**：玩家在 E1 或 E2 之后重开，发现录像带里的主角**换了名字，但说话方式一模一样**——暗示这一轮只是同一盘带子的又一次播放。

> 至少交付 E1 + E2，E3 作为"重开才看见"的隐藏层。三个结局都不做"你死了"式惩罚，全部为**认知型结局**。

## 七、技术约束（阶段四、五才展开，此处只锁边界）

- 纯前端：`HTML + CSS + 原生 JS`，**无框架、无构建工具**；
- 剧情数据外置为 `JSON`，引擎只负责"渲染文本 → 呈现选项 → 记录 flag"；
- 本地双击 `index.html` 即可运行，**不依赖服务器**（音频除外，见下条）；
- 存档只用 `localStorage`，**双槽位**：`game_save`（玩家可见）与 `meta_save`（玩家不知情的"被动记录"，第 3 层的载体）；
- 浏览器兼容目标：Chrome / Edge 最新版即可，不做移动端适配（画面按 16:9 CRT 质感做，移动端只保证不崩）；
- **音频策略**：先做**无音频版本**跑通流程，音频作为可选增强，避免第一阶段卡在素材授权上。

## 八、明确不做（Scope Out）

以下内容本作**一律不做**，任何阶段发现自己在做，都算越界：

- 不做 3D、不做实时演算画面、不做角色立绘与动画；
- 不做可见数值系统（没有血条、没有理智条、没有好感度数字）；
- 不做输入指令/自由键入；
- 不做多场景、多章节、多主角；
- 不做在线服务、账号系统、排行榜；
- 不做配音、不做真实人脸素材、不做恐怖音效堆砌。

## 九、验收标准（阶段六测试时逐条对照）

- [ ] 从标题到结局，首次通关耗时 10–15 分钟；
- [ ] 三层失控感**按顺序**发生，玩家在第 1 层无任何提示；
- [ ] E1、E2 均可独立到达，路径不交叉；
- [ ] 关掉浏览器再打开，`meta_save` 的痕迹仍在，且标题变化；
- [ ] 全文正文不超过 1200 字（不含分支重复段）；
- [ ] 全篇无突然弹出的图像/音效惊吓；
- [ ] 断网状态下双击 `index.html` 功能完整。

## 十、遗留待确认（不阻塞阶段二）

1. **主角身份**：玩家扮演"这间客厅的主人"，还是"来别人家过夜的客人"？（影响所有第一人称叙述）
2. **带子内容的形态**：带子里播的是**家庭录像**（更日常、更冷），还是**电视节目/预报**（更疏离）？
3. **克制程度**：第 3 层的"存档被改"，你能接受做到"出现不是玩家写的文字"这个强度吗？还是希望更含蓄？
4. 游戏中文名：《倒带》/**《请勿倒带》**/《B面》——可后续定。
